환경 변수 설정

Supabase·Channel Talk 키를 입력하면 .env 파일 내용을 생성합니다. 배포 환경(Vercel)에는 동일한 값을 대시보드에 등록하세요.

이 페이지는 로컬 설정용입니다. 입력한 키는 브라우저에만 남고 서버로 전송되지 않습니다. SUPABASE_SERVICE_ROLE_KEY는 절대 공개 저장소나 프론트 코드에 넣지 마세요.

1. 키 입력

공개 읽기용. API 서버 또는 RLS가 허용한 클라이언트에서만 사용.
서버(Vercel API) 전용. 브라우저에 노출 금지.

2. .env 파일로 저장

다운로드한 파일을 프로젝트 루트의 .env로 저장한 뒤 vercel dev로 API를 테스트하세요.
